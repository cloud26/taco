## 一句话

**让人与 Agent 在一个文件里共同审阅、传递和管理 spec。** 这支 50 秒的短片只讲一件事：spec 不该散落在十二个地方。

## 观众

- 每天在 PR、聊天记录和 wiki 之间来回切换的工程师；
- 想让 Agent 真正读懂人类评审意见的团队负责人；
- 讨厌「请先注册账号」的所有人。

## 核心信息

1. **一个文件就是交接物**：spec、目录结构、阅读器、编辑器与评论，全部装进一个 `.taco.html`。
2. **人负责判断，Agent 负责落地**：人在浏览器里阅读、编辑、留下锚定评论；Agent 把修改安全写回 canonical files。
3. **零配置**：只需要浏览器。离线可用，无需账号，MIT 开源。

## 成功标准

| 指标 | 目标 |
| --- | --- |
| 观众记住产品名 | 看完 10 秒内能说出「Taco」 |
| 观众理解闭环 | 能复述「打包 → 评审 → Handoff → 同步」 |
| 行动转化 | 复制安装命令 |
