## In one sentence

**Review, hand off, and manage specs with humans and agents — in one file.** This 50-second film says one thing: a spec should not be scattered across twelve places.

## Audience

- Engineers who bounce between PRs, chat threads, and the wiki all day;
- Team leads who want agents to actually understand human review feedback;
- Everyone who hates "please create an account first."

## Key messages

1. **The file is the handoff**: the spec, its directory structure, the reader, the editor, and comments all travel in one `.taco.html`.
2. **Humans judge, agents deliver**: people read, edit, and leave anchored comments in the browser; the agent writes the changes safely back to the canonical files.
3. **Zero setup**: all you need is a browser. Works offline, no account, MIT licensed.

## Success criteria

| Metric | Target |
| --- | --- |
| Viewers remember the name | Can say "Taco" within 10 seconds of the end |
| Viewers understand the loop | Can retell "pack → review → Handoff → sync" |
| Conversion | Copy the install command |
